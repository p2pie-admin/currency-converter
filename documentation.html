Converter — краткая документация

Модуль src/index.ts поднимает Fastify‑сервер, который выдаёт курсы обмена крипто/фиатных пар, рисует мини‑графики динамики и определяет город клиента по IP. Данные собираются из CoinGecko и ExchangeRatesAPI, нормализуются и сохраняются в локальной базе node-json-db вместе со списком городов, полученным из Strapi.

HTTP API

  • GET / — извлекает IP клиента через getClientIp, ищет его местоположение функцией getLocation и возвращает найденный город, координаты и сам IP.
  • GET /:dir — отдаёт последний курс направления вроде BTC_USD, дневной и часовой тренды, а также вспомогательные курсы валют к USD. Источник — массив .rates[dir] в базе.
  • GET /:dir/1h и GET /:dir/24h — подготавливают усечённый набор данных за 6 либо 24 точки, передают его в createChart и возвращают PNG‑изображение свечи/спарклайна.

Ключевые функции и процессы

normalizeIp(ip)
Удаляет хвосты вида ::ffff:, порты и локальные адреса. Используется в getClientIp.
getClientIp(req)
Извлекает IP из заголовка X-Forwarded-For или сокета Fastify, перед тем как вызвать getLocation.
createChart(data, timeframe)
Строит линию тренда через chartjs-node-canvas, добавляет градиент и светящийся маркер последней точки.
updateFiatRates()
Берёт список кодов .fiat из базы, запрашивает курс к евро в EXCHANGERATESAPI и сохраняет словарь .fiat_to_euro. При недоступности API используется хардкоженный резерв reserved.ts.
updateCryptoRates()
Подкачивает курсы выбранных монет к EUR через CoinGecko, конвертирует их в связки crypto↔fiat и fiat↔fiat функцией matchRates, округляет roundAmount и обновляет историю .rates при помощи mergeRates (хранится не более 6×24 = 144 точек, фактическая глубина зависит от частоты обновлений).
roundAmount(amount, rude)
Нормализует число до минимально значащего порядка для стабильного отображения курсов.
matchRates(aToEuro, bToEuro)
Комбинаторно строит словарь направлений вида BTC_USD → курс на основании значений к евро.
mergeRates(oldRates, newRates, limit)
Добавляет новое значение к истории направления и обрезает хвост сверх заданного лимита.
getLocation(ip)
Запрашивает ipinfo.io, парсит город и координаты, ищет почти совпадающее название в .cities (через isAlmostMatching) либо ближайший город по расстоянию (алгоритм хаверсина).
auth()
Получает JWT Strapi по AuthMutation, сохраняет его в .jwt и повторяет запросы при ошибке.
callStrapi(query, vars)
Упаковывает GraphQL‑клиент с актуальным JWT, исполняет запрос и прогоняет ответ через normalizer.
normalizer(data)
Распаковывает strapi‑структуру data → attributes в плоские объекты и массивы.

Фоновая инициализация

После запуска сервер слушает порт CONVERTER_PORT, авторизуется в Strapi, скачивает список городов, прогревает сервис геолокации и планирует таймеры: через 5 cекунд обновляет фиатные курсы, через 6 секунд — криптовалютные, далее повторяет операции каждые 30 минут и 12 часов соответственно. Все данные кешируются в node-json-db (src/db) поверх структуры из initialDB.ts.
